Project Master Directive: Sentinal (AI-Powered Content Moderation & Similarity Engine)
Role: Engineering Team Lead & Technical Architect
Objective: Orchestrate the development of Sentinal, an enterprise-grade content safety and visual similarity platform designed to analyze images and videos for safety risks, extract and evaluate embedded text, compute perceptual similarity, and output natural-language explainability reports.

Domain Selected Technologies
Primary Responsibilities
Frontend: React 18 (Vite), Tailwind CSS, Lucide React, Headless UI, Axios
Responsive dashboards, file upload pipelines, score visualizers, history views.
Backend API: Python 3.11+, FastAPI, Uvicorn, Pydantic v2
Endpoint orchestration, asynchronous queueing, authentication, file processing.
Relational DB: MySQL 8.0 with SQLAlchemy 2.0 & Alembic
User credentials, role assignments, analysis metadata, audit trails.
Vector DB: Qdrant / ChromaDB
Multimodal vector storage, cosine similarity indexing for deduplication.
AI Vision Engine: Hugging Face Falconsai/nsfw_image_detection, CLIP (ViT-B/32)
Visual safety multi-label scoring, frame-level video analysis, semantic vectorization.
OCR & NLP: Tesseract OCR (pytesseract), Python NLP RegEx/Rule Filter
Extracting embedded typography, flagging offensive slogans and toxic phrases.
Explainability: Google Gemini API (gemini-1.5-flash or gemini-2.5-flash)
Contextual reasoning and narrative synthesis of flagged visual elements.

2. Database Schema Definition (MySQL)

CREATE DATABASE IF NOT EXISTS sentinal_db;
USE sentinal_db;

CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    hashed_password VARCHAR(255) NOT NULL,
    role ENUM('USER', 'ADMIN') DEFAULT 'USER',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE analysis_records (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL,
    file_name VARCHAR(255) NOT NULL,
    file_type ENUM('IMAGE', 'VIDEO') NOT NULL,
    file_url VARCHAR(500) NOT NULL,
    analysis_type ENUM('NSFW', 'SIMILARITY', 'COMBINED') NOT NULL,
